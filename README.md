# 🚑 Medicall Call Center Organization

## 📌 Overview
This project manages and streamlines the process of recording incoming health-related calls to a call center. It is designed to securely log critical patient information into a database, including medical history (anamnesis), call dates, and efficiently assign priorities for ambulance dispatch teams.

## 🚀 Features
- **Call Logging:** Accurately records incoming call details and precise timestamps.
- **Priority Assignment:** Determines and assigns urgency levels for ambulance teams to optimize response times.
- **Anamnesis Tracking:** Stores essential patient medical history securely.
- **Database Integration:** Seamlessly saves, updates, and manages all structured records within the database.

## 🛠 Prerequisites
